# jis_null

[null] JIS keymap for the [null] ST110r2.x keyboard with VIA support.

* Layers: 0 base, 1 HEX keypad, 2 Game Mode, 3 Mouse Keypad, 4-6 Function Layers, 7 PIN layer.
* Enable VIA Support: load `st110r2_via.json` in VIA's Design tab.
* LED Brightness Control: PgUp / PgDn on layers 4-6.

## PIN lock and protected macros

See `users/null-st110r2/readme.md`. The shared code (LED, PIN lock, protected macros) lives in `users/null-st110r2`.
